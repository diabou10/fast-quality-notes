# Quality Notes Copier

Je veux créer une application web simple et ultra-rapide pour m'aider à rédiger mes notes d'évaluation qualité.
La base de données :
Voici mes données de base (ajoutes-en d'autres pour remplir l'interface) :

Recovery Pass : Le représentant a identifié le blocage du client et fourni la solution exacte.

Recovery Fail : Échec dans l'identification de la solution appropriée.

Device Match : Le modèle a été correctement identifié.

Les fonctionnalités attendues :


Une grande barre de recherche en haut.

Quand je tape un mot clé (ex: 'Recovery'), l'application doit filtrer instantanément en temps réel et afficher toutes les typologies qui contiennent ce mot.

Chaque résultat doit afficher le Titre (ex: Recovery Pass) et sa Description.

Très important : Ajoute un bouton 'Copier' à côté de chaque description pour que je puisse la copier dans mon presse-papiers en un clic.

L'interface doit être épurée, moderne (style tableau de bord) et optimisée pour aller très vite."
